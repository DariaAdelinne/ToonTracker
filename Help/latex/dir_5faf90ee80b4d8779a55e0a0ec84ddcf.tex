\hypertarget{dir_5faf90ee80b4d8779a55e0a0ec84ddcf_autotoc_md0}{}\doxysubsection{\texorpdfstring{Toon\+Tracker}{Toon\+Tracker}}\label{dir_5faf90ee80b4d8779a55e0a0ec84ddcf_autotoc_md0}
\doxylink{namespace_toon_tracker}{Toon\+Tracker} este o aplicație desktop realizată în C\# Windows Forms, destinată gestionării desenelor animate și serialelor animate urmărite de utilizator.

Aplicația permite adăugarea, editarea, ștergerea și urmărirea progresului pentru diferite titluri animate. Proiectul include și un sistem de recomandări inteligente, statistici vizuale, export de raport și mai multe teme vizuale.\hypertarget{dir_5faf90ee80b4d8779a55e0a0ec84ddcf_autotoc_md1}{}\doxysubsection{\texorpdfstring{Screenshot interfață}{Screenshot interfață}}\label{dir_5faf90ee80b4d8779a55e0a0ec84ddcf_autotoc_md1}

Aplicația are două tipuri de recomandări:\+


\begin{DoxyEnumerate}
\item {\bfseries{Recomandări automate}} ~\newline
 Acestea sunt generate pe baza desenelor sau serialelor finalizate și a scorurilor acordate.
\item {\bfseries{Recomandări personalizate}} ~\newline
 Utilizatorul poate selecta preferințe precum genuri, studiouri sau tipul serialului, iar aplicația generează sugestii potrivite.
\end{DoxyEnumerate}

Titlurile recomandate pot fi adăugate direct în wishlist cu statusul {\ttfamily Planned}.\hypertarget{dir_5faf90ee80b4d8779a55e0a0ec84ddcf_autotoc_md6}{}\doxysubsection{\texorpdfstring{Validări implementate}{Validări implementate}}\label{dir_5faf90ee80b4d8779a55e0a0ec84ddcf_autotoc_md6}
Aplicația verifică datele introduse de utilizator pentru a evita informații greșite. Exemple:\+


\begin{DoxyItemize}
\item titlul nu poate fi gol;
\item genul nu poate fi gol;
\item numărul de episoade trebuie să fie pozitiv;
\item episoadele vizionate nu pot depăși numărul total de episoade;
\item scorul nu poate fi acordat dacă nu a fost vizionat niciun episod;
\item nu pot exista două titluri cu același nume. 
\end{DoxyItemize}
